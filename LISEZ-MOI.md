# Elegance Strasbourg — dossier du projet

Ce dossier contient tout ce dont Claude Code a besoin pour développer le site et l'application de réservation.

## Contenu

| Élément | Rôle |
|---|---|
| `CLAUDE.md` | Règles de travail, lues automatiquement par Claude Code à chaque session |
| `docs/dossier-projet.md` | Document de référence : carte, 52 règles métier, 38 décisions. Il fait foi. |
| `docs/transmission-code.md` | Stack, principes d'architecture, modèle de données, 9 lots de développement |
| `docs/decisions.md` | Journal des décisions techniques, rempli par Claude Code |
| `docs/design/` | Passation de Claude Design : README, jetons, thème Tailwind, animations, et CORRECTIONS.md |
| `docs/brief-design.pdf` | Le brief envoyé à Claude Design, pour archive |
| `assets/logo/` | Logo officiel, version web |
| `assets/photos/` | Photos traitées pour le site ; `originaux/` garde les photos d'origine |

Maquettes et prototype : https://claude.ai/code/artifact/89f78eff-5469-48ae-9996-f775496f1782

## Lancer Claude Code

1. Ouvrez Claude Code sur ce dossier.
2. Collez le message de lancement de la section « Message de lancement » de `docs/transmission-code.md`.
3. Validez l'architecture et le plan du lot 0 qu'il vous propose, puis chaque lot l'un après l'autre.

Avant le lot 0, ouvrez au moins votre compte GitHub. Les autres comptes (Vercel, Supabase, Brevo, nom de domaine) viendront quand Claude Code les demandera.
